# GAME-10033 Assignment 3 Template

This template is an empty "shell" that can serve as a basis for Assignment 3. It is not a complete Visual Studio project.

It may be more useful to just browse these files to understand the structure of how to implement functions, classes and for loops.

If you choose to use the files directly, you must:
- Rename Class1.cs, Class2.cs, and Class3.cs
- Rename the class names themselves to be the proper classes in your design
- Remove all comments from the files and make your own comments as appropriate
- Remove all "Unique Functions" and replace them with your own functions

The locations of the unique functions are just suggestions and *not* required. You may create and use functions however you see fit to meet the assignment requirements.
